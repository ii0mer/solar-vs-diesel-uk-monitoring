# figures/

The ten paper figures live in `figures/paper/` and are produced by `src/figures_paper.py`. Every plotted number comes from the model or from `results/` (the same sources as `results/numbers.json`); nothing is drawn by hand. Style (module header): Liberation Sans 8 pt body and 7 pt ticks, Okabe-Ito colour-blind-safe palette with sites running warm to cool from south to north, no in-figure titles, top and right spines removed, 600 dpi PNG, column width 3.50 in and page width 7.16 in (`COL_W`, `PAGE_W`).

## To regenerate

```bash
python -m src.figures_paper
```

Requires `results/validation.json`, `results/multiyear.json` and `results/sizing_sweep_<site>.csv` (written by `python -m src.validation`, `python -m src.multiyear` and `python -m src.make_results`) and the committed weather files in `data/pvgis/` and `data/pvgis_series/`; the figures are set in Liberation Sans with Liberation Serif panel labels. `python -m src.make_all` runs the whole pipeline and ends with the figures and the tests. Legacy figure modules and the root-level `figures/*.png` from earlier versions were removed; the paper figures are the only figure outputs.
