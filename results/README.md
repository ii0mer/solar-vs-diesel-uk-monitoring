# results/

Every file in this folder is generated by the pipeline; nothing here is edited by hand. `numbers.json` is the single source of truth for every number quoted in the paper and in the repository READMEs. When two files disagree, `numbers.json` (the last file written by `python -m src.make_all` before the figures) wins.

Weather inputs: PVGIS-SARAH2 typical meteorological year (`data/pvgis/`) for the step-1 sizing and validation layer 2; PVGIS 5.2 hourly series 2005-2020 (`data/pvgis_series/`) for validation layer 1, the sixteen-year check and the final designs. All economics use the FINAL designs (`SITE_DESIGN` in `src/monte_carlo.py`): Southampton 500 Wp + 2.0 kWh, Birmingham 800 Wp + 1.5 kWh, Liverpool 550 Wp + 2.0 kWh, Edinburgh 850 Wp + 1.75 kWh.

## To regenerate

Everything, in the correct order (about ten minutes on a laptop; numba, if installed, speeds up the sixteen-year loops):

```bash
python -m src.make_all
```

Individual steps, in dependency order:

```bash
python -m src.sizing         # sizing_sweep_<site>.csv (step-1 grid)
python -m src.validation     # validation.json, validation_monthly.csv
python -m src.multiyear      # multiyear.json, multiyear_grid_<site>.csv, multiyear_lolp_matrix.csv, multiyear_summary.txt
python -m src.make_results   # sizing_summary.txt, sizing_sweep_<site>.csv, lcoe_comparison.csv, diesel_ops_summary.txt, resize_checks.txt
python -m src.monte_carlo    # monte_carlo_lcoe.csv, monte_carlo_draws_*.npz
python -m src.sweeps_2d      # sweep2d_ratio_<site>.csv, sweep2d_breakeven.csv
python -m src.dump_numbers   # numbers.json
```

`src.make_results` asserts that the module constants `SITE_DESIGN_TMY`, `LOAD_DESIGNS`, `DEGRADATION_DESIGNS` and `SITE_DESIGN_DEG08` match what the searches return, and `tests/test_validation_multiyear.py` checks `SITE_DESIGN` against `multiyear.json`. If a model parameter changes, update the constants to the new search results (`sizing_summary.txt`, `multiyear_summary.txt`, `resize_checks.txt`) and rerun `python -m src.make_all` before rebuilding the paper.
